# 01 — 随机游走与 √N

## 问题

从 0 出发，每步等概率 ±1。走 N 步之后，离原点有多远？

直觉容易给出"N 的一半"或"某个和 N 成正比的距离"——都不对。

## 结论（三个公式）

设 `X_N` 是 N 步之后的位置：

```
E[X_N]   = 0                    （对称，期望回到原点）
Var[X_N] = N                    （每步方差 +1，可加）
std[X_N] = √N
E|X_N|   = √(2N/π) ≈ 0.798·√N   （绝对值的一阶矩，用得到时查这张表）
```

关键：**方差随 N 线性增长，开方后标准差只按 √N 增长**。

## 推导（三行）

每步增量 `s_i ∈ {−1, +1}`，独立同分布，`E[s_i] = 0`、`Var[s_i] = 1`。

```
X_N = s_1 + s_2 + ... + s_N

Var[X_N] = Var[s_1] + ... + Var[s_N] = N        ← 独立性让协方差项全为 0
std[X_N] = √N
```

**"方差可加"是全部的秘密**。标准差不能直接相加——这正是直觉容易出错的地方。

## 为什么很容易误以为是 N

对比两种走法，同样 N = 4096 步：

| 走法 | 最终距离 |
|---|---|
| 一路向前（每步都 +1） | **4096** = N |
| 随机游走（每步 ±1） | **≈ 51** ≈ 0.8·√N |

**差 80 倍**。原因：确定性行走的增量同号，位移直接累加；随机行走的增量正负抵消，只剩"涨落"。

## 这个数学在哪用得上：浮点累加误差

累加 N 个数，每次加法引入一个舍入误差 `e_i`，总误差 `E = Σe_i`。

**和随机游走是同一个式子**，只要两个前提成立：

1. 每个 `e_i` 的**均值为 0**（舍入有时舍、有时进）
2. 各次舍入**相互独立**

于是 `std(E) ≈ 0.5·ULP·√N`。

两个前提怎么被破坏，以及破坏后会发生什么：

| 情况 | 误差增长 | 原因 |
|---|---|---|
| 误差随机（项与累加器量级相当） | ≈ √N | 正负抵消 |
| **误差同号**（项远小于半 ULP，每次都被舍掉） | **≈ N** | 期望不为 0，直接累加 |
| 浮点累加（ULP 随累加器变大） | N^1.2 ~ N^1.5 | 上两者之间 |

第三种是真实的 fp16 累加：`δ` 不是常数，它随累加器量级变大，所以实测斜率介于 √N（0.5）和线性（1.0）之间——在 512~4096 项的实测里是 **1.45**。

> 结论：`√N` 是"固定精度 + 随机舍入"的理想情形；一旦出现"小项被吞"，就退化成线性。这就是 fp16 在长累加、尖锐分布下崩掉的数学原因。
