# math — 数学小例子

把"证明"变成"能跑一遍的数字"。每个子目录一个独立主题，只依赖 `python3` + `numpy`。

| 目录 | 主题 | 一句话结论 |
|---|---|---|
| [`01_random_walk/`](01_random_walk/) | 随机游走与 √N | N 步随机游走后离原点的典型距离是 √N，不是 N；这解释了为什么累加误差按 √N 增长 |

## 约定

- 每个目录：`README.md`（原理 + 结论）+ 可直接运行的 `*.py` + `results/`（脚本自己生成）
- 脚本只打印**能和公式对上的数字**，不画图（避免 matplotlib 依赖）；需要看形状时用 ASCII 直方图
- 运行：`python3 <dir>/<script>.py`，都可以加 `--help`

## 怎么读

先看 README 里的公式，再跑脚本，最后对照"实测 / 理论"那一列——如果比值收敛到 1，说明你理解了；如果偏离，说明模型的某个假设不成立（这通常比公式本身更有意思）。
